# Витаминный практикум

Учебное приложение по витаминам для нутрициолога: курс с нуля, справочник форм
и дозировок, практика консультации и тренажёр в духе Duolingo — с путём уроков,
коронами, XP и интервальным повторением.

Устанавливается на айфон и **работает офлайн**.

## Установка на iPhone

1. Открыть сайт в Safari.
2. Поделиться → «На экран "Домой"».
3. Запускать с домашнего экрана — без адресной строки, с офлайном.

## Разделы

| Раздел | Что внутри |
|---|---|
| **Старт с нуля** | 9 шагов для новичка: аналогии, схемы «жир против воды» и «три стадии формы», карта из 20 витаминов с мнемониками, 7 правил, 5 заблуждений |
| **Справочник** | Все витамины: формы с пометкой классическая/активная/редкая, функции, дозировки, конвертер МЕ ⇄ мкг, заметки и избранное, поиск и фильтры |
| **Практика консультации** | Синергии, антагонизмы, 13 лекарств и что они истощают, красные флаги, верхние пределы (UL), время приёма, признаки дефицита, анализы, разбор этикетки, протокол консультации |
| **Тренажёр** | Путь из 5 разделов с уроками и экзаменами, ~200 заданий пяти типов: выбор ответа, несколько ответов, пересчёт числа, сопоставление пар, клинические кейсы |
| **Прогресс** | Кольцо готовности, серия дней с заморозкой, XP, короны, точность по раундам, очередь повторения |

## Механики обучения

- **Путь уроков** — уроки открываются последовательно, за каждый до трёх корон
- **Экзамен раздела** — 15 вопросов, порог 85 %
- **XP и цель на день** (10 / 20 / 40 XP), серия дней с заморозкой на один пропуск
- **Интервальное повторение** (Leitner: 0 / 1 / 3 / 7 / 21 день)
- **Звук и тактильный отклик** на ответы, звук отключается
- Весь прогресс — на устройстве, с резервной копией в файл

## Технически

Чистый HTML/CSS/JS без библиотек и сборщиков. Из современного: `@layer`,
палитра в `oklch`, контейнерные запросы, `:has()`, нативные `popover` и `dialog`,
View Transitions API, анимации по скроллу, `@starting-style`.
Офлайн — service worker, страховка прогресса — зеркало в IndexedDB.
Кириллица зашита в файл, поэтому текст читается даже без сети.

```
src/vitamins.html   исходник приложения (фрагмент)
src/sw.js           шаблон service worker
build.py            собирает index.html и sw.js в корне
```

После правки `src/` запустить `python3 build.py`.

## Дисклеймер

Учебный материал, не медицинское назначение. Верхние допустимые уровни приведены
по нормам EFSA и NAM; расхождения с учебными дозировками отмечены в тексте.
