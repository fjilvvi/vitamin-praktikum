# Витаминный практикум

Учебное веб-приложение по витаминам для нутрициолога: курс с нуля, справочник форм
и дозировок, практика консультации и тренажёр с интервальным повторением.

Всё приложение — **один самодостаточный HTML-файл** (`index.html`, ~180 КБ).
Ни сборки, ни зависимостей: открывается двойным кликом и работает офлайн
(без сети подставляются системные шрифты вместо Literata / Golos Text).

## Разделы

| Раздел | Что внутри |
|---|---|
| **Старт с нуля** | 9 шагов для новичка: аналогии, схемы «жир против воды» и «три стадии формы», карта из 20 витаминов с мнемониками, 7 правил, 5 заблуждений |
| **Справочник** | Все витамины: формы с пометкой классическая/активная/редкая, функции, дозировки, конвертер МЕ ⇄ мкг, отметки «выучено», поиск и фильтры |
| **Практика консультации** | Синергии, антагонизмы, 13 лекарств и что они истощают, красные флаги, верхние пределы (UL), время приёма, признаки дефицита, анализы, разбор этикетки, протокол консультации |
| **Тренажёр** | ~180 вопросов с разбором: формы, дозировки, дефициты, 27 клинических кейсов. Ошибки возвращаются по расписанию повторения |
| **Прогресс** | Кольцо готовности, серия дней, точность по раундам, слабые темы, очередь повторения |

## Возможности интерфейса

- **Светлая и тёмная темы**, выбор запоминается (по умолчанию светлая)
- Нижняя панель вкладок на телефоне, выпадающее меню на десктопе
- Интервальное повторение (Leitner, интервалы 0 / 1 / 3 / 7 / 21 день)
- Весь прогресс хранится в `localStorage` — данные никуда не передаются

## Технически

Чистый HTML/CSS/JS без библиотек. Из современного: `@layer`, палитра в `oklch`,
контейнерные запросы, `:has()`, нативный `popover`, View Transitions API,
анимации по скроллу (`animation-timeline: scroll()`), `@starting-style`.

## Дисклеймер

Учебный материал, не медицинское назначение. Верхние допустимые уровни приведены
по нормам EFSA и NAM; расхождения с учебными дозировками отмечены в тексте.
